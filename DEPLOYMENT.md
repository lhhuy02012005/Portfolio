## 🔧 If Something Goes Wrong

### Build Failed
**Location**: https://github.com/lhhuy02012005/Portfolio/actions
**Solution**:
1. Check last workflow run
2. Red X = build error
3. Click on failing run to see error message
4. Common issues:
   - YAML syntax error in _config.yml
   - Invalid Ruby in Gemfile
   - Missing closing tags in index.html

### Site Shows Old Version
**Solution**:
1. Hard refresh: `Cmd+Shift+R` (Mac) or `Ctrl+Shift+R` (Windows)
2. Clear browser cache
3. Wait 5 minutes and refresh
4. Check GitHub Actions shows "✓ build successful"

### URLs Still Showing Old Domain
**Solution**:
1. Check index.html in editor - should have `{{ site.url }}`
2. Verify _config.yml has correct baseurl: `/Portfolio`
3. Run locally: `bundle exec jekyll build` and check `_site/index.html`
4. Should see: `https://lhhuy02012005.github.io/Portfolio/` in source
